# Earlier-version gameplay

The GIF and MP4 show a 12-second excerpt from a user-provided recording of an
earlier Checkpoint Run Viewer, starting nine seconds into the recording.

The visible level is stage 4-2. The viewer was set to 2× playback speed. The crop
keeps the play area and removes the surrounding dashboard, HUD, and notifications.
Audio and MP4 source metadata are omitted.

This is a gameplay example from another version, not an evaluation of the PPO
checkpoints reported in `results/historical/`. The recording alone does not
establish the algorithm, training budget, or whether the agent reached this level
from the start of the game.
